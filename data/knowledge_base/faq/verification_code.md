# 收不到验证码常见问题

## 邮箱验证码

### 检查项
1. 确认邮箱地址输入正确
2. 检查垃圾邮件/订阅邮件文件夹
3. 等待 60 秒后点击「重新发送」
4. 确认邮箱未设置过滤规则拦截 CloudDesk 邮件

### 常见原因
- 邮件被归入垃圾邮件
- 企业邮箱防火墙拦截
- 邮箱存储空间已满
- 输入了错误的邮箱地址

## 短信验证码

### 检查项
1. 确认手机号已正确绑定
2. 检查手机信号是否正常
3. 确认未开启短信拦截/黑名单
4. 等待 60 秒后重新获取

### 常见原因
- 手机信号弱或无服务
- 短信被安全软件拦截
- 运营商短信网关延迟
- 手机号已停机

## 解决方案
- 如超过 5 分钟仍未收到，尝试更换登录方式（邮箱→手机号，或反之）
- 联系管理员确认账号绑定信息
- 拨打客服热线：400-XXX-XXXX
