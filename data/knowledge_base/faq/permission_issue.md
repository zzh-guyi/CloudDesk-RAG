# 权限问题常见问题

## 问题描述
用户反馈无法访问某些功能或项目，提示「权限不足」或「无权操作」。

## 常见场景

### 1. 无法查看项目
- 确认是否已被邀请加入项目
- 检查邀请邮件是否已接受
- 联系项目管理员添加权限

### 2. 无法编辑内容
- 确认角色是否为「编辑者」或「管理员」
- 「查看者」角色仅有只读权限
- 联系管理员调整角色

### 3. 无法邀请成员
- 仅「管理员」角色可以邀请成员
- 联系项目管理员代为邀请
- 升级角色后自行邀请

### 4. 无法删除项目
- 仅项目创建者或管理员可以删除
- 删除操作不可恢复，请谨慎操作
- 如需转移项目，可联系技术支持

## 角色说明

| 角色 | 权限范围 |
|------|----------|
| 管理员 | 全部权限，包括成员管理 |
| 编辑者 | 可编辑内容，不可管理成员 |
| 查看者 | 仅可查看，不可编辑 |

## 解决方案
- 联系项目管理员确认权限配置
- 如需变更角色，在「成员管理」中修改
- 企业版可配置自定义角色权限
