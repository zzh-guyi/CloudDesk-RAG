# CloudDesk 版本生命周期政策

## API 版本策略

- 主要版本：每季度发布，可能包含破坏性变更
- 次要版本：每月发布，向后兼容
- 补丁版本：按需发布，仅修复 Bug

## 版本支持周期

| 版本类型 | 支持周期 | 说明 |
|---------|---------|------|
| 当前版本 | 无限制 | 正常使用 |
| 上一版本 | 12 个月 | 仅安全补丁 |
| 旧版本 | 停止支持 | 需升级 |

## 升级通知

- 版本废弃前 90 天发送通知
- 版本废弃前 30 天发送提醒
- 废弃后返回 E5001 错误

## 建议

- 保持 API 客户端更新
- 关注版本更新日志
- 及时响应废弃通知
