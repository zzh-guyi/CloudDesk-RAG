# API 调用限制

## 各套餐 API 限制

| 套餐 | 请求频率限制 | 每日上限 | 说明 |
|------|-------------|---------|------|
| Free | 10 次/秒 | 1,000 次/天 | 基础限制 |
| Team | 100 次/秒 | 50,000 次/天 | 中等限制 |
| Enterprise | 1,000 次/秒 | 无限制 | 高性能限制 |

## 限制类型

- **频率限制**：每秒最多请求数（RPS）
- **总量限制**：每日最多请求数
- **并发限制**：同时进行的请求数

## 超出限制处理

- 超出频率限制：返回 429 Too Many Requests
- 超出总量限制：返回 429 Daily Limit Exceeded
- 等待下一时间窗口后重试
- 升级套餐获取更高限制

## 最佳实践

- 实现指数退避重试机制
- 批量操作使用批量接口
- 缓存频繁查询的结果
- 使用 Webhook 替代轮询
