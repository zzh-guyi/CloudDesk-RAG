# E2003 错误码详解

## 错误信息
```
E2003: Resource not found
```

## 错误含义
请求的资源不存在，通常发生在访问不存在的资源时。

## 可能原因

### 1. 资源 ID 错误
- 项目 ID、文档 ID 或任务 ID 不正确
- ID 格式错误（如包含空格或特殊字符）
- 使用了已删除资源的 ID

### 2. 资源已被删除
- 目标资源已被管理员删除
- 资源已过期待自动清理
- 资源所属项目已被删除

### 3. 权限问题
- 无权访问该资源
- 资源属于其他项目
- 账号已被移除项目成员

## 解决方案

1. **确认资源 ID**
   - 在项目列表中确认正确的资源 ID
   - 检查 URL 中的 ID 参数是否正确

2. **检查资源状态**
   - 确认资源未被删除
   - 确认资源所属项目仍然存在

3. **确认权限**
   - 确认当前账号有访问权限
   - 联系项目管理员确认成员状态

## 预防措施
- 删除资源前确认无依赖
- 定期清理无用资源
- 使用资源管理工具跟踪资源状态
