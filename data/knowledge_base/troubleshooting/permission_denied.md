# Permission Denied 错误排查

## 问题描述
操作被拒绝，提示「Permission Denied」或「无权操作」。

## 常见场景

### 1. API 权限不足
- API Key 缺少必要权限
- 请求的 Scope 未授权
- 账号类型限制

### 2. 项目权限不足
- 不是项目成员
- 角色权限不足（查看者无法编辑）
- 成员已被移除

### 3. 操作权限不足
- 删除操作需要管理员权限
- 修改设置需要管理员权限
- 批量操作需要更高权限

## 解决方案

1. **检查 API 权限**
   - 登录控制台 → API 管理
   - 确认 Key 的权限范围
   - 申请必要的 Scope

2. **确认项目角色**
   - 联系项目管理员确认角色
   - 申请升级角色
   - 确认账号状态正常

3. **使用正确的账号**
   - 确认登录的账号有操作权限
   - 企业用户确认使用了正确的企业账号
   - 检查是否在正确的项目上下文中操作

## 权限矩阵

| 操作 | 查看者 | 编辑者 | 管理员 |
|------|--------|--------|--------|
| 查看内容 | ✅ | ✅ | ✅ |
| 编辑内容 | ❌ | ✅ | ✅ |
| 邀请成员 | ❌ | ❌ | ✅ |
| 删除项目 | ❌ | ❌ | ✅ |
| 修改设置 | ❌ | ❌ | ✅ |
