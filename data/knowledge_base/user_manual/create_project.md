# 如何创建 CloudDesk 项目

## 创建步骤

1. 登录后点击首页右上角「+ 新建项目」
2. 填写项目信息：
   - 项目名称（必填，2-50个字符）
   - 项目描述（可选）
   - 选择项目模板（可选）
3. 点击「创建」

## 项目模板

- **空白项目**：从零开始构建
- **知识库项目**：快速搭建智能客服
- **数据分析项目**：内置数据可视化组件
- **工作流项目**：自动化业务流程

## 项目权限

- **创建者**：默认拥有项目管理员权限
- **成员**：由管理员邀请加入，可分配角色
- **访客**：仅查看权限，不可编辑

## 注意事项

- 免费版最多创建 3 个项目
- 团队版最多创建 20 个项目
- 企业版项目数量无限制
