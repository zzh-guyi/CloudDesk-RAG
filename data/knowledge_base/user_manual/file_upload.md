# CloudDesk 文件上传指南

## 支持的格式

- 文档：PDF, DOC, DOCX, TXT, MD, RTF
- 图片：JPG, PNG, GIF, WEBP
- 数据：CSV, XLS, XLSX, JSON
- 压缩包：ZIP, RAR

## 上传步骤

1. 进入项目 → 点击「文件」标签
2. 点击「上传文件」
3. 选择文件（支持拖拽上传）
4. 等待上传完成

## 文件限制

- 单个文件大小：免费版 10MB，团队版 100MB，企业版 500MB
- 单次上传数量：10 个文件
- 总存储空间：见套餐说明

## 常见问题

- **上传失败**：检查文件大小是否超限，或网络是否稳定
- **格式不支持**：先转换为支持的格式再上传
- **上传速度慢**：尝试分批次上传小文件
