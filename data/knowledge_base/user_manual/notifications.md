# CloudDesk 消息通知设置

## 通知类型

- **系统通知**：版本更新、维护通知
- **项目通知**：成员变更、任务分配
- **审批通知**：审批请求、审批结果
- **@提及通知**：被@时触发
- **评论通知**：收到评论时触发

## 通知渠道

- 站内消息（默认）
- 邮件通知（可在设置中开启）
- 企业微信/钉钉集成（企业版）

## 设置步骤

1. 进入「设置 → 通知设置」
2. 选择需要接收的通知类型
3. 选择通知渠道
4. 点击「保存」

## 免打扰模式

- 可设置免打扰时段（如 22:00-08:00）
- 免打扰期间通知仅站内可见，不发送邮件

## 常见问题

- **收不到邮件通知**：检查垃圾邮件箱，确认邮箱地址正确
- **如何屏蔽某类通知**：在通知设置中关闭对应类型
