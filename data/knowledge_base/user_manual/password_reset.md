# 如何修改密码

## 已知当前密码

1. 登录后进入「设置 → 安全设置 → 修改密码」
2. 输入当前密码
3. 输入新密码（8-32位，需包含字母和数字）
4. 确认新密码
5. 点击「保存」

## 忘记密码

1. 在登录页点击「忘记密码」
2. 输入注册邮箱或绑定手机号
3. 获取并输入验证码
4. 设置新密码
5. 使用新密码重新登录

## 密码要求

- 长度 8-32 位
- 至少包含一个大写字母
- 至少包含一个小写字母
- 至少包含一个数字
- 不能包含用户名或邮箱前缀
- 不能使用最近 3 次使用过的密码
