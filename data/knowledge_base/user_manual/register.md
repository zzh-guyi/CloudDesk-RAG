# 如何注册 CloudDesk 账号

## 注册步骤

1. 访问 CloudDesk 官网：https://www.cloud Desk.com
2. 点击右上角「免费注册」按钮
3. 填写以下信息：
   - 企业名称
   - 联系邮箱（将作为登录账号）
   - 设置密码（8-32位，需包含字母和数字）
   - 验证码（发送至邮箱）
4. 阅读并同意《服务条款》和《隐私政策》
5. 点击「完成注册」

## 注册后操作

- 系统会自动创建一个默认项目「我的项目」
- 首次登录建议完成企业认证，解锁全部功能
- 可在「设置 → 个人信息」中修改头像和昵称

## 注意事项

- 一个邮箱只能注册一个账号
- 企业邮箱注册后可自动获取企业管理员权限
- 个人版和企业版注册流程相同，区别在于后续认证
