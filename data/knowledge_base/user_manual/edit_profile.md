# 修改个人信息

## 修改头像

1. 点击右上角头像 → 「个人信息」
2. 点击头像区域上传新头像
3. 支持 JPG、PNG 格式，建议尺寸 200×200
4. 点击「保存」

## 修改昵称

1. 进入「个人信息」页面
2. 在「昵称」字段输入新名称
3. 点击「保存」

## 修改绑定手机号

1. 进入「安全设置」→ 「绑定手机」
2. 输入当前密码验证身份
3. 输入新手机号和验证码
4. 点击「确认绑定」

## 修改邮箱

1. 进入「安全设置」→ 「绑定邮箱」
2. 输入当前密码验证身份
3. 输入新邮箱和验证码
4. 点击「确认绑定」

## 注意事项

- 昵称修改每月最多 3 次
- 头像大小不超过 2MB
- 绑定手机/邮箱修改后，原绑定立即失效
