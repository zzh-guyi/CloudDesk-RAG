# CloudDesk 任务管理功能

## 创建任务

1. 进入项目 → 「任务」标签
2. 点击「新建任务」
3. 填写任务信息：
   - 任务名称
   - 描述
   - 截止日期
   - 指派给（可选）
   - 优先级（低/中/高）
4. 点击「创建」

## 任务状态

- **待处理**：新创建的任务
- **进行中**：正在处理的任务
- **已完成**：已完成的任务
- **已取消**：已取消的任务

## 任务协作

- 可在任务下发表评论
- @成员可触发通知
- 支持附件上传
- 任务关联子任务

## 视图模式

- **列表视图**：按时间排序
- **看板视图**：按状态分组
- **日历视图**：按截止日期查看
