# CloudDesk 错误码参考

## 认证错误（E1xxx）

| 错误码 | HTTP 状态 | 含义 | 解决方案 |
|--------|-----------|------|----------|
| E1001 | 401 | 认证凭据无效 | 检查 API Key 或账号密码 |
| E1002 | 401 | Token 已过期 | 刷新 Token 或重新登录 |
| E1003 | 401 | Token 已被废除 | 重新获取 Token |
| E1004 | 403 | 账号已被禁用 | 联系管理员 |
| E1005 | 403 | 权限不足 | 确认账号权限 |

## 资源错误（E2xxx）

| 错误码 | HTTP 状态 | 含义 | 解决方案 |
|--------|-----------|------|----------|
| E2001 | 404 | 项目不存在 | 检查项目 ID |
| E2002 | 409 | 项目名称已存在 | 使用其他名称 |
| E2003 | 404 | 资源未找到 | 检查资源 ID |
| E2004 | 403 | 权限不足 | 确认项目成员身份 |

## 上传错误（E4xxx）

| 错误码 | HTTP 状态 | 含义 | 解决方案 |
|--------|-----------|------|----------|
| E4001 | 413 | 文件过大 | 压缩文件或升级套餐 |
| E4002 | 415 | 格式不支持 | 转换文件格式 |
| E4003 | 504 | 上传超时 | 检查网络，分批上传 |
| E4004 | 507 | 存储已满 | 清理文件或升级套餐 |
| E4005 | 400 | 文件内容无效 | 检查文件是否损坏 |

## 系统错误（E5xxx）

| 错误码 | HTTP 状态 | 含义 | 解决方案 |
|--------|-----------|------|----------|
| E5001 | 500 | 服务器内部错误 | 稍后重试，联系支持 |
| E5002 | 503 | 服务不可用 | 检查服务状态 |
| E5003 | 429 | 请求过于频繁 | 降低请求频率 |
